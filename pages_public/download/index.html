WinPop 無料β版ダウンロード

Windows用インストーラーをダウンロード

WinPopは、iPhoneからWindows PCへ写真・ファイル・リンク・テキストを送れる無料β版アプリです。Windowsで開いて、確認事項を読んだうえでダウンロードしてください。

使う前に確認

  • Windows PC向けアプリです。
  • iPhoneとWindows PCが同じWi-Fi内にある状態で使います。
  • iPhone側はSafariなどのブラウザから使えます。
  • β版のため、環境によっては正常に動作しない場合があります。

Start guide

ダウンロード後にやること

最初に必要な操作だけを、短い手順で確認できます。

インストーラーを実行

ダウンロードしたファイル名を確認してから、Windows PCで実行します。

WinPopを起動

受け取りたいPCでWinPopを開き、画面に表示されるQRコードを確認します。

iPhoneでQRを読み取る

iPhoneのカメラやSafariで開き、写真・ファイル・URL・テキストを送ります。

Windowsの警告が出る場合があります

WinPopは現在、個人開発の無料β版です。リリース直後の未署名アプリのため、Windows SmartScreenなどの警告が表示される場合があります。

警告画面で「実行」ボタンが表示されない場合は、画面内の「詳細情報」を選ぶと「実行」が表示される場合があります。公式サイトからダウンロードしたファイルであることを確認したうえで、利用するか判断してください。

  • 会社・学校などの管理されたPCでは、管理者のセキュリティポリシーにより実行できない場合があります。
  • 不安がある場合は無理に進めず、公開ページ、リリース情報、配布元を確認してください。

iPhone側アプリ不要で使えます

iPhoneからWindowsにアプリなしで送りたい場合、WinPopはSafariなどのブラウザから使えます。写真・ファイル・URL・テキストを同じWi-Fi上でWindows PCへ送れます。
