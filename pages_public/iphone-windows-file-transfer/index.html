写真 ファイル URL テキスト

近くのWindows PCへ少し送るなら、同じWi-Fiの方法が手軽です

写真を数枚だけ送りたい、URLをPCで開きたい、iPhoneに新しいアプリを入れたくない。そんな時は、WindowsでWinPopを起動し、iPhoneでQRコードを読むだけで始められます。

他の送り方との違い

USBケーブル 写真をまとめて取り込む時に便利です。ケーブルと取り込み操作が必要です。
クラウドストレージ 複数端末で共有しやすい一方、アップロード待ちや容量確認が必要です。
メール・チャット 少量なら手軽ですが、添付サイズや画質、送信先の確認が気になることがあります。

WinPopなら同じWi-FiでQR接続

WinPopは、iPhone側アプリ不要・ログイン不要・クラウド不要で、同じWi-Fi上のWindows PCへ写真・ファイル・URL・テキストを送れる転送ツールです。

Windowsで起動 受け取りたいPCでWinPopを開きます。
iPhoneでQRを読み取る Safariなどのブラウザから送信画面を開きます。
送りたいものを選ぶ 写真、ファイル、URL、テキストをPCへ送れます。
PCで確認 受け取ったファイルはWindows側の保存先で確認します。

まずはWindows PCでダウンロード

WinPopは個人開発の無料β版です。未署名アプリのためWindows SmartScreenなどの警告が表示される場合があります。表示内容を確認したうえで、利用するか判断してください。

インストール前の確認

WinPopは個人開発の無料β版アプリです。リリース直後の未署名アプリのため、Windows SmartScreenなどの警告が表示される場合があります。

警告画面で「実行」ボタンが表示されない場合は、画面内の「詳細情報」を選ぶと「実行」が表示される場合があります。

公式サイトからダウンロードしたファイルであることを確認したうえで、利用するか判断してください。
